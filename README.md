# CognitioVerum

Статический каталог книг в Батуми: HTML, CSS, JavaScript, JSON. Без сборщика, базы данных, оплаты, аналитики и авторизации.

## Запуск и проверка

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
node --check assets/js/app.js
node scripts/validate-catalog.mjs
```

Не открывайте `index.html` напрямую как `file://`: браузер ограничит чтение `data/books.json`.

## Данные

`data/books.json` импортирован из листа «УЧЕТ КНИГ» таблицы «Остатки книг — цены в лари» 26.11.2026. Первоначальный импорт: 200 строк с автором, названием, ценой и числовым остатком; 172 доступные позиции / 174 экземпляра. Исходный столбец E подписан «Цена, ₾» и содержит итоговую цену (в формуле коэффициент 1,4). На сайт перенесены только отображаемые цены из E без повторного пересчёта. Внутренний столбец D не публикуется. 28 позиций с нулевым остатком сохранены со статусом `sold`; клиент их не видит. Пустые описания, категории, изображения и характеристики не придуманы.

Поля: `id` (постоянный, при первичном импорте привязан к исходному номеру строки), `author`, `title`, `category`, `description`, `price` (число в GEL), `quantity` (целое число), `status` (`available`/`sold`), `image` (путь или `null`). Можно дополнить реальными `edition` и `condition`. Разные издания и одинаковые названия хранятся отдельными записями с разными ID. В таблице две строки «Джейн Остен — Чувство и чувствительность» с ценами 16 и 21 ₾; для операции продажи нужно указать цену или ID.

При продаже находите запись по автору/названию, если есть дубликаты — по ID или цене, уменьшайте `quantity` на число проданных экземпляров, при нуле выставляйте `status: "sold"`. Не удаляйте запись. Проверяйте `node scripts/validate-catalog.mjs` перед коммитом. При следующем импорте текстов и фото сопоставляйте записи по ID, сохраняйте текущие `price`, `quantity`, `status`; номер строки таблицы не является ключом для повторного импорта.

Выбор книг хранится в `localStorage` браузера; остаток клиента не резервируется. В выбранном списке можно увеличить количество до остатка. Окончательные наличие, состояние и передача уточняются в переписке.

## Фотографии книг

Фотографии поступят отдельным ZIP-архивом. Формат: PNG, 288 × 385 px, вертикальный. В каталоге используется слот с соотношением 288:385: изображение помещается целиком без обрезки и не показывается крупнее исходного размера. Превью в каталоге и корзине загружаются по мере необходимости; в открытой карточке фотография запрашивается сразу и показывается крупнее превью.

После визуальной идентификации сохраняйте подтверждённые фотографии как `assets/images/books/<id>.png` и записывайте этот путь в поле `image` соответствующей книги в `data/books.json`. В сопроводительной таблице фиксируйте исходное имя файла, постоянный ID, автора, название и степень уверенности. Неопознанные и неоднозначные снимки оставляйте отдельно до уточнения. Не связывайте изображения с книгами по порядку файлов или по похожим названиям без сверки издания.

Ожидаются 149 фотографий и 150 физических экземпляров; число снимков не является числом позиций каталога или остатком. На одном снимке два экземпляра книги Рупи Каур «Молоко и мёд». После инвентаризации сопоставьте его с записью каталога и подтвердите количество отдельно. До этого не меняйте `quantity`, `status`, цены, названия и ID. Валидация проверяет путь, имя PNG по ID, наличие файла и размеры 288 × 385 px.

## Публикация

Репозиторий организации: `cognitioverum/cognitioverum.github.io`. Сайт опубликован по адресу https://cognitioverum.github.io/.

Workflow `.github/workflows/pages.yml` проверяет код и JSON в PR, а при обновлении ветки `main` публикует сайт через GitHub Pages. В настройках Pages источник публикации: GitHub Actions. После изменения ассортимента проверяйте валидатор каталога и результат workflow.

Сайт показывает каталог и помогает составить сообщение для Telegram или WhatsApp. Он не резервирует книги и не принимает оплату; наличие, состояние и условия передачи уточняются в переписке.
