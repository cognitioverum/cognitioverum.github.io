# CognitioVerum

Статический каталог книг в Батуми: HTML, CSS, JavaScript, JSON. Без сборщика, базы данных, оплаты, аналитики и авторизации.

## Запуск и проверка

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
node --check assets/js/app.js
node scripts/validate-catalog.mjs
```

Не открывайте `index.html` напрямую как `file://`: браузер ограничит чтение `data/books.json`.

## Данные

`data/books.json` импортирован 26.11.2026 из диапазона `A1:G149` листа «УЧЕТ КНИГ» согласованной таблицы. Столбцы A–G: остаток, автор, название, итоговая цена в GEL, имя PNG, описание и жанры. В каталоге 148 позиций, 150 экземпляров, сумма остатков 4 959 GEL. Цены перенесены числовыми без пересчёта. Жанры из колонки G разделяются точкой с запятой и хранятся в массиве `genres`; одна позиция может отображаться в нескольких фильтрах. Сайт читает только JSON и не обращается к Google Sheets.

Поля: `id` (постоянный), `author`, `title`, `genres` (массив утверждённых жанров), `description`, `price` (число в GEL), `quantity` (целое число), `status` (`available`/`sold`), `image` (путь). Можно дополнить подтверждёнными `edition` и `condition`. Для однозначных совпадений со старым каталогом сохранены прежние ID. Новым позициям выданы новые ID. Старая версия содержала два издания «Джейн Остен — Чувство и чувствительность», которые нельзя однозначно сопоставить с одной строкой нового источника; ей выдан новый ID `book-0331`.

При продаже находите запись по автору/названию и при необходимости по ID/фотографии, уменьшайте `quantity` на число проданных экземпляров, при нуле выставляйте `status: "sold"`. Не удаляйте запись. Проверяйте `node scripts/validate-catalog.mjs` перед коммитом. При последующих импортах сохраняйте постоянные ID и актуальные остатки; номер строки таблицы не является ключом.

Выбор книг хранится в `localStorage` браузера; остаток клиента не резервируется. В выбранном списке можно увеличить количество до остатка. Окончательные наличие, состояние и передача уточняются в переписке.

## Фотографии книг

Загрузите 148 файлов PNG (288 × 385 px) прямо в `assets/books/`: имена `1.png`–`149.png`, кроме `125.png`. Нужное имя для каждой позиции уже записано в поле `image` по столбцу E, независимо от номера строки. Пока файлов нет, карточка показывает монограмму CV. В каталоге используется слот с соотношением 288:385: изображение помещается целиком без обрезки и не показывается крупнее исходного размера. Превью в каталоге и корзине загружаются по мере необходимости; в открытой карточке фотография запрашивается сразу и показывается крупнее превью.

После загрузки проверьте соответствие каждого снимка названию и изданию. Валидатор проверяет уникальность имён и размер каждого загруженного PNG. Отсутствие файлов до загрузки не блокирует публикацию; число ожидающих снимков выводится в отчёте валидатора. На одной фотографии могут быть несколько физических экземпляров; количество берётся из `quantity`, а не из числа PNG.

## Публикация

Репозиторий организации: `cognitioverum/cognitioverum.github.io`. Сайт опубликован по адресу https://cognitioverum.github.io/.

Workflow `.github/workflows/pages.yml` проверяет код и JSON в PR, а при обновлении ветки `main` публикует сайт через GitHub Pages. В настройках Pages источник публикации: GitHub Actions. После изменения ассортимента проверяйте валидатор каталога и результат workflow.

Сайт показывает каталог и выбранные книги. Кнопки Telegram и WhatsApp открывают личный чат без подготовленного сообщения. Сайт не резервирует книги и не принимает оплату; наличие, состояние и условия передачи уточняются в переписке.
